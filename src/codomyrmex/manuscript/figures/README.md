# manuscript.figures

Registry-backed, provenance-stamped figure generators for the Colony Kernel
manuscript. Captions, concise alternatives, extended descriptions, and evidence
classes are resolved from the manuscript configuration; figures use direct labels or
other non-colour cues for categorical meaning.

- Shared helpers: `_common.py`
- Orchestration: `orchestrator.py`, thin script in `scripts/`
- Tests: `tests/unit/manuscript/test_figures.py`
